## dfAmmo 1.3.1

Windows x64 正式版。基于 1.3.0 的稳定性与安全性修复版本，强化了破坏性操作前的识别与窗口校验、地图文件冲突保护、配置安全以及窗口关闭体验。

### 修复与改进

- **破坏性操作精确匹配：** 删除资源卡、确认弹窗及选人界面检测改为全分辨率完整匹配，避免粗略搜索导致误判或漏判。
- **窗口与输入防误点：** 点击前再次确认目标窗口处于前台；定位启动按钮后若 WeGame 窗口发生变化则取消点击；未能确认前台窗口时超时报错中止。
- **地图文件冲突保护：** 屏蔽或恢复地图 Pak 及附属文件前先统一检查同名冲突，若同时存在正常文件与 `.disabled` 文件则中止操作并保留两份，不再静默覆盖。
- **缺失模板提示：** 缺少选人界面模板时立即报错失败，不再静默等待。
- **配置文件保护：** 配置文件无法解析且备份失败，或读取发生 I/O 错误时，本次运行禁止保存设置，避免用默认配置覆盖原文件。
- **窗口关闭等待任务结束：** 后台操作进行中关闭主窗口时，先取消并等待当前任务安全结束后再退出程序。
- **键盘导航：** 分段选择控件恢复 Tab 聚焦与左右方向键切换。

### 已知事项

- 界面依赖 Direct3D 渲染；如遇窗口空白，或在日志区右键没有菜单，请反馈并附上显卡型号。
- 如遇问题，可在 Releases 页面下载 1.3.0 覆盖解压以回退，个人配置和模板会保留。

### 使用

1. 下载 `dfAmmo-v1.3.1-windows-x64.zip`，完整解压到可写目录；无需安装 Python 或 uv。
2. **右键 `dfAmmo.exe` → “以管理员身份运行”**，确认 UAC 授权。**未使用管理员身份运行可能无法启动或执行操作。**
3. 配置游戏目录，绑定 WeGame；初次使用建议单步验证模板和操作。

不要仅移动 EXE，需保留同目录的 `_internal`、`assets` 及许可文件。首次启动会生成个人 `config.json`。

### 当前范围

- 半自动模式进入仓库并确认后结束，不循环；装备、等待地图恢复和重连由用户处理。
- 中断进度仅在程序保持运行时有效，关闭程序后不保留；点击“开始卡邮件”会清除旧进度。
- 全自动后续步骤仅占位，尚未实现。
- 游戏或 WeGame 更新、分辨率或缩放设置变化后，可能需要重新采集模板。
- 程序会发送键鼠输入、结束游戏进程及重命名资源文件；请先备份并阅读 README。
- EXE 未签名，Windows 可能显示发布者未知或 SmartScreen 提示。请核对来源与 SHA-256；不要关闭安全软件。
