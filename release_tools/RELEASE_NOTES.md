## dfAmmo 0.1.4

Windows x64 便携版本，新增版本检查、自动更新和“关于”窗口。

### 更新

- 右上角信息图标打开“关于”，查看版本、检查更新和更新并重启；更新提示统一输出到日志。
- 默认启动时检查 GitHub 正式版本，可开启空闲时自动安装更新。
- EXE 下载并校验更新包，退出后安装、重启，保留个人配置和自采模板。
- 源码版克隆对应版本；已有 Git 仓库使用快进更新并保护本地修改。
- 安装失败后暂停自动更新并记录原因，避免重启后反复尝试；可在“关于”中手动重试。

### 使用

1. 下载 `dfAmmo-v0.1.4-windows-x64.zip`，完整解压到可写目录；无需安装 Python 或 uv。
2. **右键 `dfAmmo.exe` → “以管理员身份运行”**，确认 UAC 授权。**未使用管理员身份运行可能无法启动或执行操作。**
3. 配置游戏目录，绑定 WeGame；初次使用建议单步验证模板和操作。

不要仅移动 EXE，需保留同目录的 `_internal`、`assets` 及许可文件。首次启动会生成个人 `config.json`。

### 当前范围

- 半自动模式进入仓库并确认后结束，不循环；装备、等待地图恢复和重连由用户处理。
- 全自动后续步骤仅占位，尚未实现。
- 游戏或 WeGame 更新、分辨率或缩放设置变化后，可能需要重新采集模板。
- 程序会发送键鼠输入、结束游戏进程及重命名资源文件；请先备份并阅读 README。
- EXE 未签名，Windows 可能显示发布者未知或 SmartScreen 提示。请核对来源与 SHA-256；不要关闭安全软件。
