## dfAmmo 1.2.0

Windows x64 正式版，新增 AZ3 地图支持与补齐队友检查，改进资源包操作和界面布局。

### 更新

- 新增目标地图选择，支持长弓溪谷与 AZ3，附带 AZ3 识别模板及对应 Pak 配置。
- 新增“检查补齐队友”开关，默认开启；行动前识别勾选状态，必要时开启并确认。
- 修复资源包卡片尚未完整显示就开始寻找垃圾桶的问题，等待滚动稳定，必要时继续小幅滚动。
- 按地图和用途整理模板命名，兼容旧配置；恢复地图下载时通过面板定位下载图标，无需独立按钮模板。
- 修复关闭窗口时可能出现的无效句柄错误；点击前检查目标窗口归属，键盘与滚轮统一使用 SendInput。
- 修复日志卡片底部裁切和不必要的流程滚动，调整绑定卡片布局；接管导航与重置状态移至同一行。
- 修复日志右键复制菜单的黑底显示，统一菜单配色。

### 使用

1. 下载 `dfAmmo-v1.2.0-windows-x64.zip`，完整解压到可写目录；无需安装 Python 或 uv。
2. **右键 `dfAmmo.exe` → “以管理员身份运行”**，确认 UAC 授权。**未使用管理员身份运行可能无法启动或执行操作。**
3. 配置游戏目录，绑定 WeGame；初次使用建议单步验证模板和操作。

不要仅移动 EXE，需保留同目录的 `_internal`、`assets` 及许可文件。首次启动会生成个人 `config.json`。

### 当前范围

- 半自动模式进入仓库并确认后结束，不循环；装备、等待地图恢复和重连由用户处理。
- 中断进度仅在程序保持运行时有效，关闭程序后不保留；点击“开始卡邮件”会清除旧进度。
- 全自动后续步骤仅占位，尚未实现。
- 游戏或 WeGame 更新、分辨率或缩放设置变化后，可能需要重新采集模板。
- 程序会发送键鼠输入、结束游戏进程及重命名资源文件；请先备份并阅读 README。
- EXE 未签名，Windows 可能显示发布者未知或 SmartScreen 提示。请核对来源与 SHA-256；不要关闭安全软件。
