## dfAmmo 1.3.0-beta.2

Windows x64 测试版（Pre-release）。相比 1.2.4，界面用 Qt Quick 重写，安装包从约 94 MB 减小到约 80 MB；beta.2 在 beta.1 的基础上改进了停止后的继续逻辑、识别速度和若干稳定性问题。

**这是测试版：新界面和下面的改动只做过启动检查和离线对比，完整的卡邮件流程尚未全部实测。需要稳定使用请继续用 1.2.4。** 只有在“关于”中选择测试版渠道才会收到此更新。

### 相比 beta.1

- **继续逻辑：** 停止后再继续时，以当前画面为准。游戏内导航可以往回对齐（例如取消匹配后回到大厅会重新点击出发）；WeGame 步骤和回大厅步骤会先看一次画面，已到后面的步骤就跳过，退回前面的就重做。删除地图的逻辑不变。
- **识别速度：** 模板匹配先在缩小的画面上找候选，再在原图上精确打分；2560×1600 下单次匹配从约 0.18 秒降到约 0.05 秒，结果与原来一致。
- **选人界面：** 识别阈值提高到至少 0.90，因为识别成功后会结束游戏进程。
- **Pak 恢复：** 覆盖同名文件时改为一步替换，失败时不会丢文件。
- **配置：** 保存改为先写临时文件再替换；配置文件损坏时会备份为 `config.corrupt.json`。
- **错误日志：** 程序内部错误会写入程序目录下的 `dfAmmo.log`。
- **更新：** 安装在同步或重定向目录下时不再因链接检查而无法更新；失败的更新包一天后自动清理；测试版渠道会跳过格式不符的标签。
- **其他：** 日志和输入框的右键菜单改为中文样式；任务运行中不能采集模板；缺少模板时不再空等。

### 界面

- 界面改用 Qt Quick（QML）绘制，在 125%、150% 等分数缩放下，按钮、勾选框的边缘和文字更清晰。
- 运行模式、目标地图、执行模式和更新渠道改为分段选择，切换时有滑动动画。
- 步骤按钮用颜色和图标表示待命、执行中、完成、失败；执行中的步骤有闪烁提示，停止后仍会标出停在哪一步。
- “关于”和“采集模板”改为窗口内弹层；模板保存成功或失败改为底部提示条。
- 按钮图标改用 Windows 自带的图标字体；连接卡片分两行显示窗口标题和进程信息。
- “屏蔽 Pak”按钮文字缩短，说明移到悬停提示；点击“重置状态”会同时取消待继续的步骤。

### 安装包

- 去掉用不到的组件：OpenCV 的视频库、Pillow 的 AVIF 和 WebP 等插件、Qt 的翻译文件、多余的控件风格和图片格式插件、软件 OpenGL 渲染库。
- 删除 4 张未被使用的模板图片；自行修改或采集过的同名图片在更新时会保留。

### 已知事项

- 首次启动窗口会回到屏幕中央，之后会记住位置。
- 界面依赖 Direct3D 渲染；如遇窗口空白，或在日志区右键没有菜单，请反馈并附上显卡型号。
- 如遇问题，可在 Releases 页面下载 1.2.4 覆盖解压以回退，个人配置和模板会保留。

### 使用

1. 下载 `dfAmmo-v1.3.0-beta.2-windows-x64.zip`，完整解压到可写目录；无需安装 Python 或 uv。
2. **右键 `dfAmmo.exe` → “以管理员身份运行”**，确认 UAC 授权。**未使用管理员身份运行可能无法启动或执行操作。**
3. 配置游戏目录，绑定 WeGame；初次使用建议单步验证模板和操作。

不要仅移动 EXE，需保留同目录的 `_internal`、`assets` 及许可文件。首次启动会生成个人 `config.json`。

### 当前范围

- 半自动模式进入仓库并确认后结束，不循环；装备、等待地图恢复和重连由用户处理。
- 中断进度仅在程序保持运行时有效，关闭程序后不保留；点击“开始卡邮件”会清除旧进度。
- 全自动后续步骤仅占位，尚未实现。
- 游戏或 WeGame 更新、分辨率或缩放设置变化后，可能需要重新采集模板。
- 程序会发送键鼠输入、结束游戏进程及重命名资源文件；请先备份并阅读 README。
- EXE 未签名，Windows 可能显示发布者未知或 SmartScreen 提示。请核对来源与 SHA-256；不要关闭安全软件。
