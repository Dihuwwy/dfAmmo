## dfAmmo 1.0.0

Windows x64 正式版，完善半自动流程与中断后的继续执行。

### 更新

- 停止后可点击“继续”或按 Ctrl+F12，从中断的阶段与小步骤接续。
- 统一小操作进度记录，已完成的点击和按键会跳过；游戏导航重新识别画面对齐进度。
- Pak 操作保留原定方向，避免中断后继续时反向切换。
- 移除手动暂停入口；Shift+F12 随时请求停止，单步执行及提示处理仍可继续。
- 停用全局快捷键注册，通过按键轮询响应，不占用系统快捷键。
- “关于”新增正式版/测试版更新渠道，默认只检查正式版。
- 启动游戏或打开更多菜单前检测右下角战报，出现时点击关闭；模板不包含动态战绩或高校认证信息。
- 鼠标点击统一使用 SendInput，移除旧的 mouse_event 回退。

### 使用

1. 下载 `dfAmmo-v1.0.0-windows-x64.zip`，完整解压到可写目录；无需安装 Python 或 uv。
2. **右键 `dfAmmo.exe` → “以管理员身份运行”**，确认 UAC 授权。**未使用管理员身份运行可能无法启动或执行操作。**
3. 配置游戏目录，绑定 WeGame；初次使用建议单步验证模板和操作。

不要仅移动 EXE，需保留同目录的 `_internal`、`assets` 及许可文件。首次启动会生成个人 `config.json`。

### 当前范围

- 半自动模式进入仓库并确认后结束，不循环；装备、等待地图恢复和重连由用户处理。
- 中断进度仅在程序保持运行时有效，关闭程序后不保留；点击“开始卡邮件”会清除旧进度。
- 全自动后续步骤仅占位，尚未实现。
- 游戏或 WeGame 更新、分辨率或缩放设置变化后，可能需要重新采集模板。
- 程序会发送键鼠输入、结束游戏进程及重命名资源文件；请先备份并阅读 README。
- EXE 未签名，Windows 可能显示发布者未知或 SmartScreen 提示。请核对来源与 SHA-256；不要关闭安全软件。
